# Changelog

Все значимые изменения «Верфи» документируются в этом файле. Экран версии приложения генерируется из этого источника.

Формат основан на Keep a Changelog, версии следуют Semantic Versioning.

## [Unreleased]

## [0.1.3] — 31.08.2026 — Контрастная системная шапка Android

### Изменено

- Мобильная шапка продолжает тёмный фон системной панели Android, чтобы две области воспринимались как единая поверхность.
- Практика-кандидат Werft Standard уточнена по результату проверки светлой схемы на Pixel 11 Pro.

### Исправлено

- Возвращён тёмный `theme-color` и убран принудительный светлый `color-scheme`, из-за которого часы и индикаторы становились чёрными на тёмной системной панели.

## [0.1.2] — 31.08.2026 — Мобильный экспорт и цельная системная шапка

### Добавлено

- Кнопки скачивания Markdown и JSON перенесены в панель фильтров сквозного журнала и остаются доступными на мобильных экранах.
- В Werft Standard добавлена проверяемая практика-кандидат для системных панелей Android PWA.

### Исправлено

- Светлый `theme-color` совпадает с мобильной шапкой Верфи, чтобы установленная Android PWA не создавала отдельную чёрную полосу над интерфейсом.

## [0.1.1] — 30.08.2026 — Автосверка и единый журнал экосистемы

### Добавлено

- GitHub-срез автоматически обновляется при запуске, если последняя успешная сверка старше 15 минут и OAuth-сессия активна.
- Канонический заголовок релиза поддерживает короткое человеческое название после версии и даты.
- Добавлен пошаговый контракт подключения нового приложения к экосистеме Верфи.
- Релизы самой Верфи включены в сквозной журнал и его Markdown/JSON-экспорт.

### Изменено

- Changelog-парсер принимает даты `DD.MM.YYYY` и прежние ISO-даты, нормализуя их для сортировки.
- Ручная и автоматическая сверка используют один клиентский контракт GitHub-моста.
- Декоративные окружности в Доке стабильно отцентрированы относительно launch-области карточек на desktop и мобильных экранах.

## [0.1.0] — 28.08.2026 — Первый спуск на воду

### Добавлено

- Первый local-first MVP центра управления экосистемой проектов.
- Быстрый мобильный режим «Док» для запуска приложений.
- Библиотека пяти проектов с паспортами, статусами и источниками данных.
- Сквозной журнал релизов с фильтрацией и экспортом за период.
- Визуальные напоминания, backup-политики и журнал обслуживания.
- Werft Standard v1 с доказательными проверками качества.
- Полный экспорт и восстановление локальной базы со схемой будущей синхронизации.
- Безопасный read-only GitHub-мост для выбранных репозиториев.
- Архитектурный задел под отдельную публичную витрину проектов.

### Безопасность

- GitHub App OAuth web flow усилен PKCE S256 с зашифрованным короткоживущим verifier.
- Публичные seed-данные приватного Flow очищены от внутренних идентификаторов, путей и деталей уязвимого restore-процесса.
- Локальные Vercel-метаданные, ключи и `.werft-backup` исключены из Git.
