# Верфь

Личный local-first центр управления экосистемой проектов: библиотека, релизы, обслуживание, идеи, бэкапы и единый технический стандарт.

## Команды

- `npm run dev` — локальная разработка.
- `npm run check` — версия/changelog, lint, typecheck, tests и production build.
- `npm run start` — запуск production build.

## Принципы

- GitHub — источник технических фактов; «Верфь» — источник приватных заметок, планов и обслуживания.
- Данные пользователя хранятся локально в IndexedDB.
- GitHub-интеграция работает только на чтение.
- Flow исключён из управляемых бэкапов до отдельного цикла шифрования и безопасного восстановления.
- Публичная витрина в будущем получает только явно разрешённую очищенную проекцию данных.

Подробная спецификация, архитектурные решения и production-runbook находятся в `docs/`, включая [`docs/DEPLOYMENT.md`](docs/DEPLOYMENT.md).
